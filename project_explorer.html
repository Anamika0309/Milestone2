📚 Mutual Fund FAQ Assistant

A facts-only RAG-based assistant for 5 HDFC mutual fund schemes on Groww. The system is implemented phase-wise through Phase 0 (Governance), Phase 1 (Ingestion), and Phase 2 (Retrieval). Use the sidebar to navigate all files.
